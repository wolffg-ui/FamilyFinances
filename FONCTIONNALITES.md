## 📝 Gestion des Transactions

### Ajouter une transaction
1. Cliquez sur "+ Ajouter une transaction"
2. Sélectionnez le type (💸 Dépense ou 💰 Revenu)
3. Entrez le montant
4. Sélectionnez la catégorie
5. Sélectionnez le compte
6. Cliquez "Ajouter"

### Éditer une transaction
1. Cliquez sur ✏️ (crayon) à côté de la transaction
2. Modifiez les informations (montant, catégorie, type, date, compte)
3. Cliquez "Enregistrer"

### Supprimer une transaction
1. Cliquez sur 🗑️ (corbeille) à côté de la transaction
2. C'est fait !

## 💡 Conseils d'utilisation

### 1. Paramétrer vos budgets
- Allez à l'onglet "Budgets"
- Cliquez sur "⚙️ Gérer les budgets"
- Définissez un budget pour chaque catégorie importante
- Les barres rouges vous avertiront si vous dépassez

### 2. Suivre vos dépenses mensuelles
- Onglet "Analyses"
- Voyez le graphique de vos dépenses par catégorie
- Identifiez où va votre argent

### 3. Gestion multi-comptes
- Chaque transaction est associée à un compte spécifique
- Les soldes sont automatiquement mis à jour

### 4. Éditer les erreurs
- Si vous vous êtes trompé, cliquez sur le crayon
- Modifiez et sauvegardez
